#Quiz Game. We have to learn the Fetch API to build REST Client & JS Modules to organize an App's codebase.


In this lab, you will build a Quiz Game with a Leaderboard. See the lab document for further details. All starting files are contained within this repo.
Objectives :
* Fetch API to send requests to REST Endpoints
* REST Client architecture for developing a distributed application
* Asynchronous JavaScript with async/await functions
* JS Modules with import/export statements for improved modularity of codebase
* Scheduling and Clearing Timed Events
