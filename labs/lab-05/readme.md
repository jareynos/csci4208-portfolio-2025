 Fast-paced Dodger game built from ground up. We're going to see Object-Oriented Programming in this lab. We're gonna take Phaser and extend it with our own custom code. The whole point of this assignment is to have a fully functional game and have a much deeper understanding of modern Javascript applications. 

 What you will Learn
 * Build a complete Dodger Game that runs in a browser.
     * Structuring a Project will help us Organize code and assets for a clean web application.
     * Master the Phaser Game Loop by understanding preload, create, and update methods, which are used to form the foundation of a Phaser game scene.
     * Defining Custom Game Objects are gonna be essential; we have to build our Player, Enemy, Projectile and PowerUp as JS classes with its own properties and behaviors.
     * Leverage Inheritance - Extend core Phaser classes like Phaser.Scene to make custom objects work seamlessly within the game engine.
     * Managing Game State is useful for handling dynamic events.
