In this lab we explored and learned the basic principles of JavaScript. Developed the classic Hi-Lo game, applying basic html knowledge and the JavaScript knowledege learned. We learned to use Document Object Model API & Javascript to make interactive HTML-based Apps. 

We build a different variant of the Hi-Lo game that runs in Browser using JavaScript & Dom API.

Learning Objectives
* Document Object Model API to access and update HTML
* Event driven System design
* Agile practices: MVP
* Model-View-Controller Design Pattern
