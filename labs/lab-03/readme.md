Developed a basic web portfolio template using bootstrap. Learned the basic concepts about bootstrap and it's importance for today's web pages. Our goal was to build a responsive portfolio where you can share information about you and your skills.

Learning Objectives:
* We learned to import Bootstrap into an HTML document
* We learned Bootstrap for colors, text, spacing
* Bootstrap for aligning rows, columns, flex
* Cards & Card groups
* Collapsible Navbar
